# log-utilities
 
Набор утилит для управления логами через консольные команды.
 
- **minigrep** — позволяет находить паттерны в файлах/stdin и выводить их в stdout. Имеется набор флагов, доступных при вводе `-h`.
- **sensor-stats** — позволяет собрать статистику с разных приборов с расчетом минимального и максимального значений, среднего, медианного и среднеквадратичного отклонения. Требует указывать файл с логами при вызове.
- **logrotate** — помогает в управлении файлами логов: сжимает их в архив и позволяет настраивать размер исходников и количество сохраняемых архивов после всей обработки.
## Установка
 
Требуется Python 3.12 или новее.
 
Создайте чистое виртуальное окружение:
 
```bash
# Windows
python -m venv venv
venv\Scripts\activate.bat
 
# Linux
python3 -m venv venv
source venv/bin/activate
```
 
Скачайте исходный код к себе в папку и установите:
 
```bash
pip install <путь к папке с кодом>
```
 
Для разработки используйте флаг `-e`, это позволит редактировать код и сразу подхватывать изменения.
 
## Использование
 
### minigrep
 
```
minigrep PATTERN FILE FLAGS
```
 
Флаги:
 
- `-i` — позволяет сделать поиск регистронезависимым
- `-v` — инверсный поиск, показывает строки, где нет искомого паттерна
- `-n` — добавляет номер строки в вывод
- `-c` — показывает только количество найденных строк на файл
Чтобы программа корректно работала под Windows, раскрытие `*` происходит с помощью `glob()`. В Linux файлы раскроются дважды и поведение может отличаться от ожидаемого.
 
Коды возврата: `0` — совпадения есть, `1` — совпадений нет, `2` — ошибка.
 
Примеры:
 
```bash
minigrep "error" app.log
Get-Content app_log.log | minigrep "error"
```
 
### sensor-stats
 
```
sensor-stats FILE
```
 
Ожидает формат CSV с 3 колонками и разделением через `;`. Поля: `timestamp`, `sensor_id`, `value`.
 
Подсчитывает количество ошибок по разным типам и отбрасывает битые строки. Пишет счетчик ошибок в stderr, таблицу — в stdout.
 
Пример:
 
```bash
sensor-stats text_file.csv
```
 
### logrotate
 
```
logrotate DIR FLAGS
```
 
Флаги:
 
- `--size-mb` — архивирует логи больше указанного размера, без указания флага архивируется все
- `--keep` — позволяет задать максимальное количество архивов на диске, без указания флага сохраняется 5 штук
- `--dry-run` — печатает порядок действий без их выполнения
Примеры:
 
```bash
logrotate . --keep 1 --dry-run
logrotate .
```

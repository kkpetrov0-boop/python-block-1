Что есть в deque, чего нет в моем методе:
'appendleft', 'extendleft', 'popleft', - повторяют свои обычные версии, только с другого конца
'copy', - возвращает копию deque
'count',  - возвращает количество совпадений с переданым значением
'index', - возвращает первый индекс переданного значения
'insert', - вставляет значение перед переданным индексом
'maxlen', - возвращает максимальную длину deque - атрибут
'pop', - удаляет элемент справа
'remove', - удаляет первое вхождение элемента
'reverse', - делает разворот всего deque
'rotate' - поворот на указоное кол-во шагов

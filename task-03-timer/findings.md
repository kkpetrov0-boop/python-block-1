Используем глобальную переменную для счетчика вложенности.
Такой подход может сломаться при многопоточности

Возврат True из exit - гасит исключение. Ошибка вообще не прилетает.
Аналог - except, но надо вручную обрабатывать нужные исключения
Однако, возврат True гасит все исключения, что может быть опасно при отладке.

Повторный вход - класс падает явно, сделано вручную, через флаг экземпляра.
Реализация через менеджера падает сама - генератор одноразовый

Смешанная вложенность работает, так как счетчик глобальнный.
